# 📋 АРХИТЕКТУРНАЯ СПЕЦИФИКАЦИЯ ПРОЕКТА: VOX PWA

> **Назначение документа:** Официальный архитектурный паспорт проекта и исчерпывающее техническое задание для модели **Claude Sonnet** для реализации согласованных доработок (мультиязычность, шеринг, умная установка PWA, SEO-генератор).

---

## 1. ОБЩАЯ КОНЦЕПЦИЯ И ЦЕЛИ

* **Продукт:** Легковесное, виральное Progressive Web App (PWA) — платформа анонимных веб-чатов со специальными психологическими и игровыми режимами.
* **Вход:** Мгновенный, в 1 клик, без логина, без паролей, без форм регистрации.
* **Адаптивность:** Mobile-first (смартфоны iOS/Android) и Desktop (ПК/планшеты).
* **Стиль интерфейса:** *Obsidian Cyber-Minimalism* (глубокий темный фон `#0B0F17`, неоновые цветовые акценты под каждый режим, glassmorphism-панели, строгие профессиональные векторные иконки без мультяшности).

---

## 2. СИСТЕМНОЕ ОКРУЖЕНИЕ И ТЕХНОЛОГИЧЕСКИЙ СТЕК

* **Окружение сервера и сборки:**
  * Node.js: `v24.14.0`
  * npm: `11.9.0`
  * ОС: Windows (PowerShell)
* **Backend:**
  * Ядро: **Node.js (TypeScript) + Fastify** (высокая производительность).
  * Realtime-транспорт: **Socket.io v4** (авто-реконнект, комнаты, heartbeat).
  * State & Matchmaking: **In-Memory (Node.js Map / Set)** — ультранизкая задержка 0.1 мс.
  * Persistence & SEO: **SQLite** (`node:sqlite` DatabaseSync) — хранение шедевров + генерация страниц `/story/:slug` с динамическими OpenGraph-тегами.
* **Frontend:**
  * Фреймворк: **Vite + React 18/19 (TypeScript)**.
  * Стилизация: **Tailwind CSS**.
  * Иконки: **Lucide React** (монохромные, строгие).
  * PWA: **vite-plugin-pwa** (Web App Manifest, standalone display mode, Service Worker).
  * Тактильность: **Web Vibration API (Haptic Feedback)**.

## 3. ДЕТАЛЬНАЯ СПЕЦИФИКАЦИЯ РЕЖИМОВ И ИНТЕРФЕЙСА

### А. ШАПКА ПРИЛОЖЕНИЯ (HEADER)
В шапке слева направо располагаются:
1. **Логотип `VOX`:** клик возвращает в лобби.
2. **Кнопка «By Virus-X creators»:**
   * Темная аккуратная плашка с оранжевым текстом (`border-orange-500/30 text-orange-400`).
   * Ссылка: `https://virx-topic-pulse.com/search/virus-x.html` (открывается в новой вкладке `target="_blank"`).
3. **Кнопка «Поделиться» (Share):**
   * Размещается сразу правее кнопки «By Virus-X creators».
   * Строгая иконка `Share2`.
   * **Логика работы:**
     * На смартфонах: вызывает нативный `navigator.share()` (открывает системное меню мессенджеров Telegram, WhatsApp и т.д.).
     * На ПК / при отсутствии поддержки: копирует ссылку в буфер обмена с всплывающим тостом `✓ Ссылка скопирована!`.
   * **Текст сообщения при шеринге:**
     * *RU:* «Анонимный чат с крутыми режимами: "Два окна / Цепь", "Кислородный баллон" (лимит слов) и "Рентген" (посимвольный ввод). Вход в 1 клик без регистрации!» + ссылка на корень сайта.
     * *EN:* «VOX — anonymous fast web chat with unique modes: "Dual Chain", "Oxygen Tank" (word limit), and "X-Ray" (realtime keystroke). Instant 1-click entry without registration!» + ссылка на корень сайта.
4. **Счетчик онлайна:** пульсирующая зеленая точка + количество пользователей в сети.
5. **Тумблер языка `[ 🌐 RU | EN ]`:**
   * Автоматически определяет язык при первом визите (`navigator.language`). Если русскоязычный регион (`ru`, `be`, `uk`, `kk`) — включается `RU`, для остальных — `EN`.
   * Позволяет переключить язык в 1 клик, сохраняет выбор в `localStorage`.
6. **Кнопка «Шедевры»:** переход в каталог сохраненных диалогов Кислородного режима.
7. **Кнопка установки PWA («Установить»):**
   * **Скрытие:** если сайт УЖЕ открыт как установленное приложение (`window.matchMedia('(display-mode: standalone)').matches` или `navigator.standalone === true`), кнопка **полностью скрыта**.
   * **Android / Chrome / Edge:** вызывает системный нативный диалог установки PWA.
   * **iOS Safari:** открывает строгую темную карточку-модалку (Bottom Sheet) с актуальными пунктами меню Apple:
     1. Нажмите кнопку **Поделиться** *(иконка квадрата со стрелкой вверх `[ ↑ ]`)* на нижней панели Safari.
     2. Прокрутите меню и выберите **«На экран "Домой"»** (RU) / **"Add to Home Screen"** (EN) *(иконка квадрата с плюсиком `[ + ]`)*.

### Б. СПЕЦИФИКАЦИЯ 4 РЕЖИМОВ ЧАТА

#### 1. «Классический Тет-а-Тет» (1-на-1)
* Быстрый диалог со случайным собеседником на выбранном языке.
* Свои реплики — справа (синий градиент), чужие — слева (серый фон).
* Кнопки «Следующий» и «Выйти».

#### 2. «Два Окна / Цепной Узел» (ФЛАГМАН)
* **Топология:** Открытая эластичная цепь: $\dots \longleftrightarrow \text{А} \longleftrightarrow \text{ВЫ} \longleftrightarrow \text{Б} \longleftrightarrow \dots$
* **Языковая изоляция:** Две полностью независимые параллельные цепи — **Русская цепь** (`chain_ru`) и **Английская цепь** (`chain_en`).
* **Адаптивный интерфейс:**
  * На ПК: параллельный сплит-экран 50/50.
  * На смартфонах: «Свайп-мост» с вкладками `[Собеседник А]` и `[Собеседник Б]` и светящейся неоновой точкой активности на неактивной вкладке.
* **Кнопка пересылки (`⇄`):** мгновенный перенос текста в поле ввода соседнего окна (со свайпом вкладки на мобильном). **СТРОГО БЕЗ МЕТОК «Переслано»** — сохраняется 100% интрига.
* **Авто-сшивание цепи (Auto-Stitch):** при выходе узла цепь стягивается напрямую (`А <-> Б`) с уведомлением *«Звено цепи обновилось»*.

#### 3. «Кислородный баллон» (500 слов + ампула 200)
* **Базовый запас:** ровно **500 слов на двоих**.
* **Аварийная ампула:** ровно **+200 слов** (по 1 ампуле на участника за сессию).
* **Телеметрия:** живой процентный манометр, учет сожженных слов каждым участником.
* **«Гильотина»:** жесткое отсечение сообщения ровно на последнем слове при достижении нуля (`... [ГИЛЬОТИНА]`) с тактильной вибрацией `[120, 60, 250]`.
* **Виральный SEO-маховик («Шедевры»):**
  * Кнопка *«Сохранить шедевр»* сохраняет диалог в SQLite с пометкой языка `lang: 'ru' | 'en'`.
  * В каталоге русскоязычные видят русские диалоги, англоязычные — английские.
  * **Умный SEO Title (Защита от дублей "Привет"):**
    * Сервер фильтрует дежурные приветствия (`Привет`, `Хай`, `Hello`, `Hi` и т.д.).
    * Находит самую яркую и содержательную реплику (или фразу перед Гильотиной).
    * Формирует динамический мета-тег:
      * *RU:* `og:title = «Диалог на {totalWords} слов перед Гильотиной: "{Цитата...}" — VOX»`
      * *EN:* `og:title = «Oxygen Masterpiece ({totalWords} words): "{Quote...}" — VOX»`

#### 4. «Чат-Рентген» (Keystroke 1-на-1)
* Чат без кнопки «Отправить»: посимвольный поток с троттлингом 40 мс.
* При нажатии `Backspace` стертые слова не пропадают, а падают в полупрозрачный зачеркнутый **призрачный слой черновика** (Ghost Layer).

## 4. ЯЗЫКОВАЯ ИЗОЛЯЦИЯ НА СЕРВЕРЕ (БЭКЕНД)

В сокет-событиях передачи очередей передается параметр языка `lang: 'ru' | 'en'`:
1. `matchmaker.ts`:
   * Очереди 1-на-1 разделены: `classic_ru` / `classic_en`, `oxygen_ru` / `oxygen_en`, `xray_ru` / `xray_en`.
2. `chainEngine.ts`:
   * Раздельные структуры узлов: `chain_ru` и `chain_en`.
3. `storyRepository.ts`:
   * Таблица `stories` содержит поле `lang TEXT NOT NULL DEFAULT 'ru'`.
   * Ручка `GET /api/stories?lang=ru` отдает истории на выбранном языке.
